# 🍽️ MessMate – Daily Mess Menu Website

### Your Daily Mess Menu, All in One Place!

MessMate is a student-focused web application designed to make daily mess menu information easy to access and share.

It helps students check what food is available for breakfast, lunch, snacks and dinner.

## ✨ Features

- 🍳 Daily Breakfast menu
- 🍛 Daily Lunch menu
- ☕ Daily Snacks menu
- 🌙 Daily Dinner menu
- 📝 Students can submit daily food updates.
- 👍 Confirm menu information.
- 🚩 Report incorrect information.
- 💡 Suggest corrections.
- 📱 Responsive design for mobile and laptop screens.

## 🛠️ Technologies Used

- HTML – Website structure
- CSS – Styling and responsive design
- JavaScript – Interactive features
- Python – Backend programming
- Flask – Web framework
- SQLite – Database storage

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 🎯 Project Goal

The main goal of MessMate is to solve a common student problem: not knowing the daily mess menu in advance.

This project is an independent student learning project and is not an official college application.
